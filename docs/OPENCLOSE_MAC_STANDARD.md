# OpenClose Mac 专用标准

版本：1.0 · 2026-09-05

适用：OpenClose 系列 macOS 本地工具、后台辅助程序和对应 GitHub 项目。
来源：OpenClose 本地 AI 工具应用固定规范 v1.0；保留服务普通用户、无障碍优先和统一文档原则，调整 Windows 专属约定。
检索词：OpenClose Standard、OpenClose Standards、OpenClose Mac、Mac 专用标准、统一工具标准、README。

## 1. 产品与无障碍

先说明为谁解决什么问题。重要操作支持键盘，适用的界面需有 VoiceOver 可读名称、明确状态和焦点。第一屏提供实际功能，后台工具无需添加无意义窗口。快捷键避开系统及用户已有操作，测试真实按键效果。普通用户不应需要安装 Python、操作依赖或理解端口。

## 2. 技术选择

选择适合功能的最小架构：后台工具可用 Python 加 macOS 原生接口；本地交互工具可用 Flask/浏览器；有必要时使用原生界面。不强制给所有工具添加 Web 服务。
本地语音无需 API Key；只有产品确实使用云模型才加入凭证配置和模型回退。离线能力、联网条件和数据传输范围必须明确。

## 3. 目录与数据

项目根目录放 README.md（GitHub）、README.txt（普通用户）、使用说明.txt、LICENSE、config.txt（无秘密模板）。技术文件放 app_files/，测试放 app_files/tests/，构建产物放 build/ 和 dist/，两者不提交 Git。
应用资源只读：打包时从 sys._MEIPASS 或 app bundle 读取；运行时不要写入 .app 或 PyInstaller 临时目录。
配置、状态：~/Library/Application Support/OpenClose/应用名/
日志：~/Library/Logs/OpenClose/应用名/
缓存：~/Library/Caches/OpenClose/应用名/
登录启动：~/Library/LaunchAgents/；仅为需要登录启动的产品设置用户级 LaunchAgent，并提供停止和取消启动的方法。
程序应提供一处明确的状态入口和参数路径，避免靠全盘搜索诊断。

## 5. Mac 打包

## 中英文与国际使用

面向 GitHub 用户的项目同时提供完整英文 README 和中文说明。正式产品名在语言版本之间保持一致。应用提示、错误和帮助文案按语言配置选择；英文版语音工具使用实际安装的英文语音，不能仅翻译 README。中文与英文语速分别设置合理默认值，已有用户参数不自动覆盖。明确语言切换步骤、共用或独立的配置路径，以及是否实际翻译正文。测试英文默认值、提示路径和真实英文语音；不得将“完整英文版”描述成所有国家语言均已支持。

## Mac 打包细则

普通用户双击应用名.app，包内自带所需 Python 运行时。优先安装到 ~/Applications 或 /Applications；程序不会因临时下载路径变化而失去登录启动目标。
发布目录命名 应用名_Mac_版本号/，只包含 .app、用户说明、适用的配置模板和许可证声明。区分源码仓库与下载发布包。
明确 Apple Silicon、Intel 或 Universal 的实际支持范围、已测试 macOS 版本。诚实说明 ad-hoc 签名、Developer ID 和公证状态；不得要求关闭 Gatekeeper 或全局安全功能。
升级前保留可恢复旧版本；先测试构建候选，再替换已安装应用，保留用户参数。重启后验证真实工作流。

## 6. 版本、隐私与仓库

应用状态、README、使用说明、构建目录和 app bundle 版本保持一致。0.1.x 用于早期维护，0.2.x 用于明显功能增加；不要仅因一次打包就宣称 1.0 稳定。
源码仓库排除虚拟环境、缓存、日志、会话数据、凭证及个人绝对路径。公开前按真实数据核验；不要把测试样例中的 secret 字样当作真实泄密。
说明读取哪些本机数据、哪些模式向外发送文字、日志和缓存保留什么。可使用合适的源码许可证，并保留第三方依赖要求。含来源不明音频或图片时先排除；Apple 系统声音只调用，不复制分发。
OpenClose 蜗牛是可选品牌母题；有明确用途且有授权素材时再使用，不阻碍无障碍操作。

## 7. 验收

检查用户入口、状态接口、正常功能、暂停/恢复或退出（适用时）、配置读取和日志。后台进程“存活”不等于功能正常，朗读程序应核对实际语音进程及用户体验。
运行与变更相关的测试；构建后验证签名及包内资源；记录已验证环境和未验证范围。发布前检查 Git 暂存清单，上传后验证远端文件和提交一致。
