GPT Monitor Windows 版 · 自动朗读本机 Codex 回复
版本 0.2.0 · OpenClose · 作者：刘天华
邮箱：robert.liu656@gmail.com

【这是给谁用的】
Windows 视障用户，以及希望通过听觉接收新回复的用户。

【这是什么软件 / 为什么需要它】
后台读取本机 Codex 新助手回复，使用 Windows SAPI 语音朗读，减少反复查找屏幕消息。与 Mac 版共用内部信息过滤及去重模块，不翻译正文。

【使用方法】
完整解压到固定文件夹，双击 GPTMonitor.exe。听到开始监听提示后，在 Codex 中生成新回复。没有主窗口，不自动添加开机启动项。
Ctrl＋Alt＋斜杠：暂停／恢复当前朗读。暂停期间新回复会忽略。
Ctrl＋Alt＋Q：退出。再次双击程序启动。
斜杠使用美式键盘对应的 OEM_2 物理键，其他布局可能显示不同符号。
本 Windows 版本按顺序朗读队列，暂不具备 Mac 版新任务打断优先功能。

【系统要求】
64 位 Windows 10/11，已安装可供 SAPI 调用的语音。中文需要兼容的中文 SAPI 语音；并非“讲述人”里所有声音都可被 SAPI 调用。
打包版不需要安装 Python。构建和自动测试在 GitHub Windows 环境进行；真实电脑扬声器、屏幕阅读器和按键体验仍需实机验证。未验证 Windows ARM 或 32 位系统。
程序未进行 Authenticode 签名，SmartScreen 或单位管理策略可能提示或阻止运行。请核对下载来源，不要关闭安全软件。

【配置 / API Key / 模型自动切换】
无需 API Key，无需联网合成语音，不使用问答模型。
实际配置：%LOCALAPPDATA%\OpenClose\GPT Monitor\config.txt
包内配置仅在首次启动复制。已有配置不会被覆盖；中英文版共用配置且只运行一份。
切换语言：退出程序，用对应包的 config.txt 替换运行配置，再启动。
language=zh-CN 或 en-US；voice_name 留空自动按语言选音，或填写已安装 SAPI 声音名称的部分文字。
rate 默认 0，范围 -10 到 10，是 SAPI 速度等级，不是每分钟字数。
volume 默认 70，范围 0 到 100。缺少声音时会给出错误提示并退出。

【常见问题 / 隐私】
无声时检查暂停状态、输出设备及声音安装。退出后重新启动可重建监听。
status.json 和 monitor.log 位于配置同目录。状态带时间戳，不能单凭旧状态认定进程正在运行。
日志只记录元数据、会话文件名和状态，不记录完整回复正文；默认合成完全本地。
只支持 ~/.codex/sessions 中的本机 Codex 会话，网页或纯云端任务可能没有这些文件。不会在启动时补读所有旧消息。
